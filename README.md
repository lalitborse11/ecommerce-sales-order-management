# E-Commerce Sales & Order Management System

## 📌 Project Overview

This project is a PostgreSQL-based E-Commerce Sales & Order Management System designed to manage and analyze customers, products, orders, payments, shipping, reviews, and returns.

## 🎯 Objectives

- Manage customer and product information
- Track orders and order items
- Manage payments, shipping, reviews, and returns
- Analyze sales and product performance
- Identify top-selling products
- Analyze customer segments and retention
- Monitor inventory and order status

## 🛠️ Technologies Used

- PostgreSQL
- SQL
- DBMS

## 📊 Database Tables

- Products
- Orders

- Payments

- Returns

## 📈 Business Analysis

The project includes analysis of:

- Sales Revenue
- Top-Selling Products

- Customer Segments
- Inventory Status

- Order Status
- Customer Reviews
- Returns
- Customer Retention
